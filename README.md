# CCF QQ 频道提醒

把 CCFOLIA 公开频道的新消息提醒发送到 QQ 私聊或群聊。通过 OneBot v11 正向 WebSocket 独立运行，可与海豹骰并行使用。

- 任意 QQ 用户都可使用；群内所有成员可管理该群已绑定房间的订阅。
- 默认订阅 `MAIN`；`全频道` 订阅当前及今后新增的公开频道。
- 私聊登记一次账号后，可在任意聊天窗口订阅新的房间。
- 状态列出房间名、频道名及网址。频道可按名称关闭；全频道模式下关闭的频道保持排除。
- 提醒仅含房间、频道、北京时间及发言者，不转发正文、图片或骰点。
- 首次订阅从当前开始；断线及重启后分页补收，并按稳定消息 ID 去重。

## 安装

需要 Python 3.10 或更高版本、已登录的 OneBot v11 服务及可访问 CCFOLIA/Firebase 的网络。Linux 可使用 systemd 用户服务：

```bash
./install.sh \
  --onebot-url ws://127.0.0.1:3001 \
  --napcat-config /path/to/onebot11_ACCOUNT.json \
  --napcat-port 3001
systemctl --user enable --now ccf-qq-relay.service
```

安装器支持 `--dry-run`。手动安装、升级与备份见[安装说明](docs/安装说明.md)。

## 使用

私聊骰子登记账号。密码中的空格会保留；也可只发送 `。ccf提醒 登记`，按提示在下一条私聊提供邮箱和密码。

```text
。ccf提醒 登记 YOUR_EMAIL YOUR_PASSWORD
```

在接收提醒的 QQ 私聊或群里发送：

```text
.ccf提醒 https://ccfolia.com/rooms/ROOM_ID
.ccf提醒 全频道 https://ccfolia.com/rooms/ROOM_ID
.ccf提醒 https://ccfolia.com/rooms/ROOM_ID 全频道
```

| 指令 | 作用 |
|---|---|
| `.ccf提醒` | 帮助 |
| `.ccf提醒 INFO <房间网址>` | 增加指定公开频道 |
| `.ccf提醒 频道 <房间网址>` | 列出公开频道 |
| `.ccf提醒 测试 <房间网址>` | 用最新现有公开消息核对访问及提醒格式 |
| `.ccf提醒 测试 INFO <房间网址>` | 测试指定频道 |
| `.ccf提醒 状态` | 列出本窗口的房间、频道、网址及连接状态 |
| `.ccf提醒 关闭 INFO` | 按名称关闭；同名有歧义时须附房间网址 |
| `.ccf提醒 关闭 INFO <房间网址>` | 关闭该频道，在全频道订阅中保持排除 |
| `.ccf提醒 关闭 <房间网址>` | 关闭该房间全部频道及自动发现 |
| `.ccf提醒 关闭` | 关闭本窗口全部订阅及自动发现 |

测试不会创建订阅、推进处理进度或改变防刷屏状态。已绑定房间的群成员可直接增减频道，无需另行登记。详细语法与防刷屏规则见[使用说明](docs/使用说明.md)。

## 发布包

`.tar.gz` 与 `.zip` 包含相同的独立源码及安装器；`SHA256SUMS` 校验压缩包，包内 `MANIFEST.sha256` 校验文件。构建器只纳入公开程序、示例配置、文档及测试，排除配置、数据库、日志、虚拟环境和运行备份。

```bash
python3 package_release.py --version 1.1.0
python3 -m unittest discover -s tests -p 'test_*.py'
```

## 凭据与边界

登记仅保存邮箱及可续期登录令牌，不保存明文密码。令牌足以访问账号获准读取的房间，数据库须按凭据保护。QQ、NapCat 及其他骰子程序仍可能记录原始私聊指令。

只处理当前登录账号可读的公开消息；私信、私密频道、暗骰及已删除消息不提醒。支持邮箱密码登录，第三方交互登录不适用。源站接口或权限变化可能要求更新程序或重新登记。

同一数据库只能运行一个服务。QQ 已接受消息而本地尚未记账时发生故障，重试仍可能重复；补收前已删除的消息无法恢复。
