# CCF QQ 频道提醒：使用说明

订阅按「房间 × 公开频道 × QQ 窗口」独立保存。所有 QQ 用户均可使用，旧配置中的 `allowed_user`、`allowed_users` 不产生权限限制。群内所有成员可管理该群已绑定的房间。

## 私聊登记账号

私聊骰子发送：

```text
。ccf提醒 登记 YOUR_EMAIL YOUR_PASSWORD
```

也可先发送 `。ccf提醒 登记`，在 10 分钟内用下一条私聊发送邮箱和密码，以空格或换行分隔。邮箱后的全部内容作为密码，保留密码中的空格。登记成功后不需要为每个新房间重复提供凭据。

仅支持 CCFOLIA 邮箱密码登录。账号登记只能私聊进行。程序保存邮箱、登录令牌及刷新令牌，不保存明文密码；令牌允许持续访问账号获准读取的房间。数据库、备份和 QQ 原始私聊记录均应妥善保护。

原有私聊绑定语法仍可使用：

```text
.ccf提醒 https://ccfolia.com/rooms/ROOM_ID YOUR_EMAIL YOUR_PASSWORD
.ccf提醒 INFO https://ccfolia.com/rooms/ROOM_ID YOUR_EMAIL YOUR_PASSWORD
```

带账号密码时，频道或 `全频道` 必须放在网址前，密码后不要附加选项。

## 订阅频道

在需要接收提醒的 QQ 窗口发送：

```text
.ccf提醒 https://ccfolia.com/rooms/ROOM_ID
.ccf提醒 INFO https://ccfolia.com/rooms/ROOM_ID
.ccf提醒 https://ccfolia.com/rooms/ROOM_ID OTHER
```

未指定频道时订阅 `MAIN`。重复订阅同一频道保留现有订阅起点、去重记录、防刷屏状态和待发提醒。

群聊订阅新房间可使用发令者已登记的账号；房间已在该群绑定后，所有群成员都可利用现有可用登录身份增减频道。群内不会显示登录凭据。私聊窗口不能复用另一 QQ 用户的私聊身份。

频道按完整名称或频道 ID 匹配。订阅名称含空格的频道时可使用频道 ID；关闭指令支持包含空格的完整频道名。名称重复时使用 ID；跨房间的名称有歧义时附上房间网址。

## 全频道订阅

以下两种写法等价：

```text
.ccf提醒 全频道 https://ccfolia.com/rooms/ROOM_ID
.ccf提醒 https://ccfolia.com/rooms/ROOM_ID 全频道
```

加入该房间当前所有公开频道，并在每轮消息轮询时刷新频道列表。新增公开频道会自动加入，从全频道订阅开始时间补收其消息。私密频道及私信始终排除。

可在当前窗口仅按频道名取消一个频道：

```text
.ccf提醒 关闭 INFO
.ccf提醒 关闭 Side Chat
```

被关闭的频道记录为排除项，轮询和重启不会重新加入。其他频道及后续新频道继续提醒。显式再次订阅该频道可恢复；再次发送该房间的 `全频道` 指令会恢复所有排除频道。

关闭房间或关闭整个窗口会同时停止其自动发现。即使当前所有频道都已单独关闭，只要没有关闭房间，全频道规则仍会发现其他新增公开频道。

## 查询与测试

| 指令 | 作用 |
|---|---|
| `.ccf提醒` | 查看帮助 |
| `.ccf提醒 频道 <房间网址>` | 列出可读公开频道及必要的频道 ID |
| `.ccf提醒 状态` | 查看本窗口全部订阅 |
| `.ccf提醒 状态 <房间网址>` | 查看指定房间 |
| `.ccf提醒 测试 <房间网址>` | 用房间最新现有公开消息检查访问与提醒格式 |
| `.ccf提醒 测试 INFO <房间网址>` | 用指定频道最新现有公开消息测试 |
| `.ccf提醒 关闭 INFO` | 按频道名称或 ID 关闭，歧义时拒绝修改 |
| `.ccf提醒 关闭 INFO <房间网址>` | 关闭指定房间的一个频道 |
| `.ccf提醒 关闭 <房间网址>` | 关闭该房间及其全频道规则 |
| `.ccf提醒 关闭` | 关闭本窗口全部频道及全频道规则 |

状态逐项列出房间名、频道名、房间网址、连接状态、高频暂停情况及待发数量；全频道规则另显示自动发现和排除数量。

测试使用已登记或已绑定身份，只读取现有消息，不创建订阅、推进去重进度或改变防刷屏状态。范围内没有现有公开消息时会说明访问成功但没有可用测试消息。测试消息发送至发令窗口。

## 提醒格式

```text
「示例房间-MAIN」[20:34:56] 示例昵称回复了。
```

时间取源消息创建时间，转换为北京时间；昵称使用源消息显示名。提醒不包含正文、图片、附件或骰点。编辑及删除不另发提醒；普通公开骰点消息与普通发言同样计数。

首次订阅不追发既有历史。断线及重启后，按创建时间分页补收订阅起点后的消息，以稳定消息 ID 去重。每轮刷新公开频道状态；周期完整扫描可以发现延迟可见的消息。

## 防刷屏

各频道分别计算，不区分发言者：

1. 连续三条可提醒新消息，两次相邻间隔均不超过 90 秒：前两条正常提醒，第三条改为高频暂停提示。
2. 暂停期间不逐条提醒；该频道下一条可提醒消息重新计算 5 分钟静默期。
3. 静默满 300 秒，成功完成源消息核查后，发送最后一条消息的时间、发言者及恢复提示。

```text
监测到「示例房间-MAIN」高频回复。超过5分钟无人回复前，不再提醒该频道消息。
「示例房间-MAIN」最后一条消息由[20:34:56] 示例昵称 回复。重新开始提醒该频道消息。
```

源断线或补收未完成时暂缓恢复。暂停状态及待发提醒持久保存；重启、测试及重复订阅不清空。

## 运行边界

程序只读 CCF 房间和消息，不代发 CCF 发言，也不修改源站房间、频道或账号设置。登录失效或权限不足时可重新私聊登记；旧式房间绑定可用原语法重新绑定。

QQ 不可用时，本地排队并重试；失败目标不会阻塞其他目标。QQ 已接受消息而本地尚未记账时发生故障，重试可能重复。源消息在补收前已删除则无法恢复。已排队的提醒只含元数据，源消息之后删除或改为私密时不会自动撤回。
